# Дашборд продаж продуктовой сети «Соседушка»

## Задача
Руководитель сети хочет понимать динамику продаж, эффективность магазинов,
влияние карт лояльности и сезонность.

## Данные
- 80 тыс. записей о продажах за 2 года
- fact_sales + справочники: товары, магазины, клиенты, поставщики
- Звездная модель в Power BI

## Что сделано
- Проверка и подготовка данных в Power Query
- Построение звездной модели
- Создание мер DAX: выручка, средний чек, чеки, клиенты, YoY, YTD
- Дашборд из двух страниц: «Обзор» и «Детали»
- Срезы, drill-down, tooltips и навигация
