# Дашборд продаж продуктовой сети "Соседушка"

Аналитический проект: интерактивный дашборд Power BI для руководителя сети продуктовых магазинов + исследовательская аналитика в Python (Google Colab).

## Задача

Руководитель сети хочет понимать динамику продаж, эффективность магазинов, влияние карт лояльности и сезонность. Вопросы, на которые отвечает проект:

1. **Где растем / проседаем** - выручка по месяцам, YoY, динамика по регионам
2. **Лучшие / худшие магазины** - рейтинг точек по выручке, чекам, среднему чеку
3. **Помогают ли карты лояльности** - сравнение среднего чека с картой и без
4. **Сезонность** - пики и провалы выручки по месяцам, неделям, часам

Дополнительно проведено исследование драйверов роста выручки в 2025 году.

## Данные

- 81 238 записей о продажах за 2 полных года (01.01.2024–31.12.2025)
- Звездная модель: таблица фактов `fact_sales` + справочники `dim_products` (101 товар, 14 категорий), `dim_stores` (20 магазинов: 4 гипермаркета, 9 супермаркетов, 7 "у дома"), `dim_customers` (5000 клиентов)
- Ограничение данных: `id_клиента` заполнен в 55% чеков - покупки без карты лояльности, демография доступна только для идентифицированных покупок

## Что сделано

- Проверка и подготовка данных в Power Query
- Звездная модель (факт + справочники, календарь)
- Меры DAX: выручка, средний чек, количество чеков, YoY, YTD, активные покупатели в месяц
- Дашборд из трех страниц: "Дашборд", "Описание", "Итоги"
- Срезы (период, регион, магазин, категория, бренд, тип покупки), drill-down по форматам магазинов, кнопочная навигация

## Ключевые выводы

1. **Сеть растет**: все месяцы 2025 положительны к прошлому году (от +3.6% до +17.6% YoY). В 2024 регионы двигались синхронно, в 2025 синхронность сломалась - аномалии по регионам описаны в ноутбуке.
2. **Магазины**: лидеры - гипермаркеты и столичные точки. Формат "у дома" работает на частоту визитов (трафик выше супермаркетов при самом низком среднем чеке). В Нижегородской области нет гипермаркетов - лидеры региона формируются супермаркетами.
3. **Карты лояльности**: лояльные покупатели дают 54% выручки и больше чеков, но их средний чек стабильно ниже (948 против 976 руб.). Карта не увеличивает чек, работает через частоту визитов и удержание. Эффективность программы следует оценивать через LTV, а не средний чек.
4. **Сезонность сетевая**: пик - декабрь и пятница-суббота, вечерний максимум в 17.00, провал - февраль (люди реже приходили, а не тратили меньше). Промо-механики можно планировать едиными для сети.
5. **Драйверы роста 2025 (дополнительно)**: рост обеспечен трафиком (+6.8% чеков, +2.8% средний чек) при активной реактивации клиентской базы (волна возврата с пиком в первом квартале 2025 перекрыла отток - без нее идентифицированная выручка была бы на ~20% ниже). Источник волны требует данных маркетинга.
